# 公開閲覧・ホーム・Shortsの修正

2026-11-15。GAS固有の画面・ハッシュルーター・RPC通信を保持し、通常版と共通の修正を反映しました。

- Google連携の確認失敗時にも公開ホームを読み込みます。個人向けフィード・Shortsの一時的失敗は公開データへ切り替えます。
- SNSの現在のフィード・検索を再試行し、公開プロフィール投稿をアプリ内で表示します。
- ストーリー取得中のサービス切り替え・キャンセル後に古い結果を表示しないようにしました。

APIのCloudflare配信と検証結果: https://github.com/Xerox-Pro/XeroxYT-NTv7-APIv1/blob/main/docs/cloudflare-frontend.md

Instagram公開検索・TikTok公開おすすめは提供元の拒否・上限が残っています。ストーリー、DM、ノート・ストーリー投稿の復旧を保証する変更ではありません。

このソース変更をGAS版へ配信するには、既存のGAS assets公開ワークフローと更新手順を実行してください。今回Vercelへの配信は行っていません。
